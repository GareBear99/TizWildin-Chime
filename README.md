# TizWildin-Chime

Large multi-part chime collection centered on an 88 BPM family of glass, void, halo, reed, and neon-synthwave material.

## What this repo contains
This repository preserves multiple related Chime pack drops instead of flattening them into one normalized folder. The root layout intentionally keeps both the earlier hero-pack folders and the later clean regenerated `Part-*` editions.

| Folder | Role | Typical contents |
|---|---|---|
| `Chime/` | Full base chime pack | one-shots, multis, loops, textures, FX, docs, scripts |
| `Void_Chime/` | Darker void-leaning companion pack | one-shots, multis, loops, textures, FX |
| `III/`, `IV/`, `V/` | Additional hero segments | one-shots, multis, loops, textures, FX |
| `Part-I_Glass-Drive/` to `Part-V_Neon-Synthwave/` | Clean regenerated editions of the segment lanes | one-shots, multis, loops, textures, FX, scripts |

## Common format
- 44.1 kHz WAV
- 88 BPM family
- each segment typically includes 16 one-shots, 25 multis, 6 loops, 4 textures, and 4 FX

## Structure note
This cleanup keeps the audio assets where they already live and focuses on making the root repo easier to browse. If you want a future normalization pass, it should be done deliberately as a separate reorganization rather than by silently deleting or merging folders.
